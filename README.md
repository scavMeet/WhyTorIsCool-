# 🧅 Почему Tor — это круто?

Привет! Сегодня мы простым языком разберем, что такое сеть Tor, зачем она нужна и кто ею пользуется.

> **Интересный факт:** прямо в ту секунду, пока вы читаете это предложение, сетью Tor пользуются **более 2 миллионов человек** по всему миру. Это огромное сообщество, объединенное идеей приватности.
